1 Neon — SQL エディタでテーブル作成

Neon は PostgreSQL のクラウド。ここに人生カレンダーのデータを保存します。

neon.tech › プロジェクト › SQL Editor
手順
  1. neon.tech でログイン → New Project
  2. 左メニュー SQL Editor を開く
  3. 下の SQL を貼り付け → Run をクリック
  4. 左 Tables で app_data ができたか確認
  5. Connection details から接続文字列をコピー → DATABASE_URL に使う
-- scripts/init-db.sql と同じ
CREATE TABLE IF NOT EXISTS app_data (
user_id TEXT PRIMARY KEY,
payload JSONB NOT NULL,
updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS app_data_updated_at_idx
ON app_data (updated_at DESC);

Run 後に Success が出れば OK。2回目以降は IF NOT EXISTS で安全です。

2 Google Cloud — OAuth クライアント

「Google でログイン」を動かすための鍵を Google 側で発行します。

Google Cloud Console の流れ
  1. console.cloud.google.com → プロジェクト作成
  2. APIとサービス → 認証情報 → OAuth クライアント ID（ウェブアプリ）
  3. 承認済みのリダイレクト URI に追加:
    • http://localhost:3000/api/auth/callback/google（ローカル）
    • https://あなたのドメイン.vercel.app/api/auth/callback/google（本番）
  4. クライアント ID → AUTH_GOOGLE_ID、シークレット → AUTH_GOOGLE_CLIENT_SECRET

3 環境変数（.env.local）

.env.example をコピーして .env.local を作ります。

.env.local（例）
AUTH_SECRET=（ランダム32文字以上）
AUTH_GOOGLE_ID=xxx.apps.googleusercontent.com
AUTH_GOOGLE_CLIENT_SECRET=GOCSPX-...
ALLOWED_EMAIL=あなた@gmail.com
DATABASE_URL=postgresql://...@ep-xxx.neon.tech/...
AUTH_SECRETPowerShell で長いランダム文字列を作るか、generator を使用
ALLOWED_EMAILここに書いた Gmail だけがログインできます
ローカルで動作確認 
$ npm install
$ npm run dev
→ http://localhost:3000 → Google でログイン

4 Vercel にデプロイ

GitHub に push 済みなら、Vercel とリポジトリを連携するのが簡単です。

方法 A: Vercel ダッシュボード（おすすめ）
  1. vercel.com → Add New Project
  2. GitHub の komeda-akira/life-schedule をインポート
  3. Environment Variables にステップ3と同じ5つを追加
  4. 本番でエラーが出たら AUTH_TRUST_HOST=true も追加
  5. Deploy → 表示された URL が本番アドレス
  6. Google のリダイレクト URI に本番 URL を追加
方法 B: CLI
npx vercel login
npx vercel --prod
